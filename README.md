# vpnctl

Личный VLESS-туннель под управлением с мака: один сервер (3x-ui/Xray), клиент —
`sing-box`, локальный или полный перехват трафика (TUN). Состояние (кто заведён,
какие ссылки рабочие) всегда собирается из живого сервера, а не из отдельного
файла с паролями — файл рано или поздно разойдётся с реальностью, реестр,
собранный `collect.py`, — нет.

Три способа пользоваться: терминал (`./vpn ...`), веб-морда в браузере
(`./vpn морда`), нативное macOS-приложение (`app/vpnctl.app`) — все три ходят
в один и тот же `ui_server.py`.

## Требования

- macOS (Apple Silicon или Intel), `sudo` для режима полного перехвата
- [`sing-box`](https://sing-box.sagernet.org/) (`brew install sing-box`)
- Python 3 (системный, ничего дополнительно ставить не нужно)
- Сервер с [3x-ui](https://github.com/MHSanaei/3x-ui) — доступ по SSH-ключу
- (опционально) `qrencode` для QR-кодов в морде, `swiftc` (Xcode CLT) для
  сборки `.app`

## Быстрый старт

Полная инструкция с нуля (провижининг сервера, все известные грабли,
рассчитана на то, что её можно дать любому агенту без контекста этого
проекта) — [`DEPLOY.md`](DEPLOY.md). Ниже — сокращённая версия для тех, у
кого сервер с 3x-ui уже настроен.

1. Скопируй `setup.example.md` → `setup.md` и `servers.example.json` →
   `servers.json`, заполни своими данными (IP, SSH-ключ, панель) — оба файла
   в `.gitignore`, наружу не уйдут.
2. Собери состояние с сервера:
   ```bash
   python3 collect.py
   ```
3. Запусти локальный режим (без root, SOCKS-прокси):
   ```bash
   ./vpn старт
   curl --socks5 127.0.0.1:2080 https://api.ipify.org   # должен показать IP сервера
   ./vpn стоп
   ```
4. Для полного перехвата трафика — один раз опубликовать привилегированную
   часть (создаёт узкое sudoers-правило только на запуск/остановку туннеля,
   ничего больше):
   ```bash
   ./vpn опубликовать
   ./vpn перехват
   ```

## Команды

```
./vpn старт                         — локальный режим (SOCKS 127.0.0.1:2080), без root
./vpn перехват                      — полный перехват трафика (TUN), нужен sudo (см. ./vpn опубликовать)
./vpn стоп                          — остановить, в каком бы режиме ни был поднят
./vpn статус                        — жив ли, какой узел активен, сколько серверов доступно
./vpn лог                           — хвост лога sing-box
./vpn диагностика                   — сеть до/после старт-стоп, проверки интернета, не блокирует
./vpn ссылки [--server X --protocol Y]  — клиентские ссылки из реального состояния
./vpn обнови                        — собрать реестр (collect.py) + обновить списки маршрутизации
./vpn конфиг <устройство>           — ссылки для конкретного заведённого устройства/человека
./vpn морда                         — открыть локальную морду (мак, полный доступ)
./vpn люди                          — список серверов/людей
./vpn добавь <имя> [--days N]       — завести человека на всех серверах
./vpn убери <имя>                   — убрать человека со всех серверов
./vpn сторож [--поставить]          — присмотр за серверами: статус или установка
./vpn опубликовать                  — перенести привилегированную часть в root-владение
```

## Морда

`./vpn морда` — веб-интерфейс на `127.0.0.1:7890`: статус туннеля и внешний
IP, переключение режима (авто / вручную / direct), список узлов с задержкой
и кнопкой «держаться этого», серверы и заведённые доступы с трафиком и
QR-кодом, форма для добавления внешних `vless://`-ссылок (не с ваших
серверов).

Отдельно есть read-only версия (`ui_server_readonly.py`) для развёртывания
на самой VPS — доступна только изнутри собственного туннеля, без прав на
управление (см. `deploy_ui.py`).

## Приложение

```bash
bash app/build.sh
open app/vpnctl.app
```

Настоящее macOS-приложение вокруг той же морды: иконка в Dock, Cmd+Tab, без
браузера. Только системные средства (`swiftc`, `WKWebView`) — никаких
Electron/Tauri.

## Меню-бар

Плагин для [SwiftBar](https://github.com/swiftbar/SwiftBar):
`brew install --cask swiftbar`, затем `menubar/install.sh`. Показывает флаг
страны активного узла, задержку, позволяет переключать режим и закреплять
узел прямо из строки меню.

## Архитектура

Личный контур: `sing-box` в режиме TUN (`172.19.0.1/30`, `gvisor`,
`auto_route`+`strict_route`) либо локальный SOCKS/HTTP на 127.0.0.1:2080.
Группы `авто` (urltest по всем живым узлам) / `вручную` (закрепление одного)
/ `выбор` (переключатель между ними и `direct`, он же `final` маршрута).
Правила маршрутизации: служебный DNS-хайджек → морда напрямую →
приватные/корп-адреса напрямую → рекламные домены reject → мессенджеры и
избранные сервисы через тоннель → российские зоны/geoip напрямую → всё
остальное через `выбор`.

Привилегированная часть (`privileged/vpn-run`) изолирована от остального
кода: `sudoers`-правило разрешает запускать только её, и только команды
старт/стоп туннеля — не произвольный `sudo`.

Полная история решений и найденных по дороге особенностей связки
sing-box/3x-ui/Xray — в [`промт-повторить-vpnctl.md`](промт-повторить-vpnctl.md)
(исходное ТЗ) и в git-истории.

## Секреты

`setup.md`, `state/`, `*.ovpn`, скачанные ruleset'ы и собранный `.app` — всё
в `.gitignore`. Паролей, API-токенов и UUID клиентов в репозитории нет —
только в `setup.md` (локально). `servers.json` в этом репозитории — реальный
рабочий файл с IP сервера, не шаблон; если заводишь свой контур, замени его
на свои значения (структура — как есть, только `host`/`ssh.ключ` свои).
